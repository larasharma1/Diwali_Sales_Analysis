# Diwali Sales Analysis

## Overview

Exploratory Data Analysis of Diwali sales data using Python to understand customer purchasing behavior and identify sales trends.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis

* Customer demographics
* State-wise sales
* Occupation-wise analysis
* Product category analysis
* Gender and age-group analysis
* Orders and sales amount

## Key Insights

The analysis identifies customer segments, locations, occupations, and product categories contributing significantly to Diwali sales.
